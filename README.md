# Yumeal

**Discover delicious recipes for every craving.**

Yumeal is a recipe discovery website that helps users explore meals,
browse food categories, view recipe details, and save their favorite recipes.

Built with HTML, CSS, and JavaScript, Yumeal uses TheMealDB API to
retrieve meal information and recipe data.

## Features

- **Discover Recipes** - Explore meals from different cuisines.
- **Search Meals** - Find recipes by name.
- **Browse Categories** - Discover meals by food category.
- **Recipe Details** - View ingredients, measurements, and cooking instructions.
- **Favorites** - Save and revisit your favorite recipes.
- **Responsive Design** - Browse recipes on different screen sizes.

## Built With

- HTML5
- CSS3
- JavaScript
- TheMealDB API
- Local Storage

## API

Yumeal uses TheMealDB API to retrieve meal information, categories,
ingredients, and cooking instructions.

- API Provider: [TheMealDB](https://www.themealdb.com/)

## Getting Started

1. Clone this repository:

   \```bash
   git clone https://github.com/Micaxa/Yumeal.git
   \```

2. Open the project folder:

   \```bash
   cd Yumeal
   \```

3. Open `index.html` in your browser or use a local development server.
